## 📌 Overview

A straightforward hospital management system focused on fast clinical data entry, doctor appointment records, and patient medical history.

---

## ✨ Key Features

- 📋 **Patient Registration & Lookup**: Fast search by patient CNIC/ID and phone number.
- 🩺 **Doctor Appointment Registry**: Schedule consultations with automatic date-time collision checks.
- 📊 **Department Management**: Radiology, Pathology, Cardiology, and General Medicine management.

---

## 🛠️ Tech Stack & Tools

- **HTML5 / CSS3**
- **JavaScript**
- **PHP / Node.js**
- **MySQL / SQLite**
